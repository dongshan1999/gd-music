> 一句话定位：播放器页是挂在全屏弹窗宿主上的「正在播放」详情页，上半区在唱片封面与歌词之间切换，下半区是进度条、播放模式、上一首/下一首/队列与收藏；它不直接操作音频节点，所有播放动作都转给全局播放状态控制器。

## 1. 功能概述

- **用户视角**：从迷你播放器、歌单、本地音乐任意一处开始播放后进入本页；点封面进歌词（可上下拖动、松手跳到居中那句），点歌词空白回封面；拖动进度条可跳转、松手才真正 seek；模式按钮在「列表循环 → 单曲循环 → 随机」间切换；另有心形收藏、插件曲目下载、队列入口、歌名/歌手点击修错名。
- **实现视角**：场景 `assets/scenes/ui/music_app/player/music_app_player_page.tscn` 根 `PlayerPage` 挂 `MusicAppPlayerView`；数据经 `MusicAppPlayerController` 从播放/状态控制器读取；不做轮询，View 订阅 `PlaybackStartedEvent` / `PlaybackFinishedEvent` / `PlaybackProgressChangedEvent`（`assets/scripts/ui/music_app/views/player/music_app_player_view.gd:152-154`）驱动 `refresh()`。
- **不在本期范围（与任务描述的偏差，以代码为准）**：
  - 页面没有「分享」「评论」按钮：全场景与脚本中均无 share/comment 相关节点或处理函数；
  - 页面没有「后台音频连接状态」展示：右上角 `PlayerSourceChip` 显示的是曲目音源名 `track.source`（`assets/scripts/ui/music_app/views/player/music_app_player_view.gd:199`），不是 Android 后台音频服务的连接状态；
  - 本页不负责解析歌词文本，只读取 `TrackData.lyric_path`（见歌词文档）。

## 4. 关键实现

### 4.1 全屏宿主 + 底部上滑

播放器页场景**没有**写 `popup_layer`，这利用了 `DX_PopupView` 的默认值 `FULLSCREEN`（`dx/runtime/scripts/managers/popup/popup_view.gd:9`），因此它挂在 `FullscreenPopupHost`（`assets/scenes/music_app_showcase_scene.tscn:69`）。该宿主在场景树中位于 `MiniPlayer`（`:65`）之后，未做任何隐藏逻辑就已覆盖迷你播放器（见 [迷你播放器](2026-10-27_迷你播放器.md)）。

场景只声明了 `presentation = 2`（`assets/scenes/ui/music_app/player/music_app_player_page.tscn:81`，即 `SHEET`）。`MusicAppPage._travel()` 对 `SHEET` 返回 `Vector2(0, min(size.y * 0.4, 300))`（`assets/scripts/ui/music_app/music_app_page.gd:52-58`），于是播放器从底部上滑进入，关闭时下滑退出。

### 4.2 封面页与歌词页的双层切换

`CoverStage`（`:235`）下同时存在 `AlbumStage`（`:242`）和 `LyricsStage`（`:301`），用可见性 + 0.18 秒淡入切换：

```gdscript
# assets/scripts/ui/music_app/views/player/music_app_player_view.gd:530-537（节选）
album_stage.visible = not _is_lyrics_visible
lyrics_stage.visible = _is_lyrics_visible
var content := lyrics_stage if _is_lyrics_visible else album_stage
content.modulate.a = 0.0
create_tween().tween_property(content, "modulate:a", 1.0, 0.18)
```

显示歌词时先 `_hide_lyrics_time_cursor()`（`:517`），再按当前曲目和已播时间重建歌词（`:521-522`）；函数开头有 `is_node_ready()` 守卫，避免 `_ready` 前被调。点击歌词页但歌词为空时，`_on_lyrics_stage_gui_input()` 会切回封面（`:397-410`），避免用户困在「暂无歌词」页。

### 4.3 进度拖动：拖动只改 UI，松手才 seek

这是本页最核心的取舍。mpv 后端的 seek 是 `absolute+exact`，每次都要重新定位解码，几十毫秒起步；拖动时一秒可产生几十个 drag 事件，若逐个下发会同时堵住主线程与 mpv 线程：

```gdscript
# assets/scripts/ui/music_app/views/player/music_app_player_view.gd:910-923（节选）
# 拖动只动 UI、不发 seek：mpv 的 absolute+exact 每次都要重新定位解码，
# 一秒几十个 drag 事件会把主线程和 mpv 线程一起堵死；真正跳转留到松手那一次。
func _preview_progress_drag(global_x: float) -> void:
	player_progress_bar.value = progress_ratio * 100.0
	elapsed_label.text = _format_seconds(int(round(progress_ratio * float(duration))))
```

配套的三个细节：

1. `_input()`（`:816-845`）在 `_is_progress_dragging` 时全局接管鼠标移动与触摸，手指移出进度条也不会断；
2. 松手时先 `_seek_player_from_global_x(..., true)` 再 `_finish_progress_drag()`，且**不立即 refresh**（`:868-872`），否则 mpv 还没吐出新 `time-pos`，进度条会先回旧位置再跳回，视觉上「顿一下」；
3. 松手后 350ms 静默窗口（`:902` + `refresh()` 的 `:216`）内，每秒进度事件不会覆盖手指位置。

实际 seek 还会被全局控制器夹到 `duration - 1` 秒（`assets/scripts/ui/music_app/controllers/global/music_app_audio_controller.gd:275-284`），因为「seek 到流长度」会被 Godot/mpv 当成自然播放结束，可能误触发自动切歌。

### 4.4 播放模式

`ShuffleButton` 一个按钮承载三种模式，图标与 tooltip 每次 `refresh()` 重设（`assets/scripts/ui/music_app/views/player/music_app_player_view.gd:161-165`）。文案不直接写中文，而是 `tr(_player_controller.get_playback_mode_label_key())`，保证中英切换；模式值属于存档字段，跨曲目、跨启动保留。

### 4.5 收藏：顺手刷新首页

```gdscript
# assets/scripts/ui/music_app/controllers/music_app_player_controller.gd:99-107（节选）
var home_popup = get_popup_router_controller().get_popup(DX_PopupRegistry.PopupId.MUSIC_APP_HOME)
if home_popup != null and home_popup.has_method("refresh"):
	home_popup.refresh()   # 首页不监听收藏信号，由播放器页主动刷新
show_toast(tr("music_app.toast.favorite_added" if next_state else "music_app.toast.favorite_removed"))
```

首页不监听收藏信号（见首页文档 4.5），所以由播放器页主动刷新；用 `has_method("refresh")` 判断而不是强转类型，避免首页未创建或改实现时抛错。

### 4.6 封面：三级兜底与请求防串

- **来源与本地/远程**：`MusicAppPlaybackStateController.get_track_artwork_source()`（`assets/scripts/ui/music_app/controllers/global/music_app_audio_controller.gd:1260-1264`）先取插件 `plugin_data.artwork`，没有则取本地音频内嵌封面缓存图，协议相对地址 `//` 补成 `https:`（`:1273-1274`）；本地走 `FileAccess.file_exists` + `Image.load_from_file`（`assets/scripts/ui/music_app/views/player/music_app_player_view.gd:594-602`），远程走 `HTTPRequest`、10 秒超时（`:38`、`:609-611`），先按后缀 `jpg/png/webp` 解码再逐个尝试（`:624-627`）。
- **防串请求**：每次换曲 `_artwork_request_id += 1`，异步回调回来先比对 `request_id` 与 `source`（`:584-587`、`:617-618`），丢弃过期结果，避免快速切歌时旧封面盖住新封面。
- **缓存与占位**：成功纹理写入 `_artwork_texture_cache[source]`（`:590`），同来源不二次下载；无封面时显示 `CoverIconRect` + 播放时呼吸缩放（`:636-648`，1.018 往返 1.8 秒）；封面尺寸 `clamp(min(stage - 24), 48, 340)`（`:630-633`），短屏不溢出。

### 4.7 下载按钮：插件曲目专属，二次点击删除

`_refresh_download_button()`（`:332-371`）决定按钮可见性与图标：

| 状态 | 表现 | 依据 |
| --- | --- | --- |
| 无下载控制器 / 非插件曲目（`plugin_id` 为空） | 按钮隐藏 | `:336-338` |
| 下载中 | 按钮禁用，文案为百分比，tooltip 显示已收/总量 | `:341-362` |
| 已下载 / 未下载 | `CHECKED` 图标 + 「已下载，再次点击删除」tooltip / `DOWNLOAD` 图标 | `:364-371` |

删除是「二次点击确认」而不是弹窗：第一次点击记下 `_download_delete_armed_track_id` 与时间戳并提示「已下载，再点一次删除」（`:320-322`），3 秒内再点才真正 `remove_download()`（`:304-319`）。这样既避免误删，又不打断播放。

`NowTitleLabel` / `NowArtistLabel` 被改成可点击（`mouse_filter = STOP` + 手型光标，`:98-106`），点击打开 `MUSIC_APP_TRACK_EDIT` 弹窗（`:115-118`）。这是为插件曲目准备的「手动修错名」通道：插件返回的标题/UP 主经常带后缀。队列按钮直接打开 `MUSIC_APP_PLAYBACK_QUEUE`（`:111-112`），队列页是另一个弹窗，见 [播放队列](2026-10-27_播放队列.md)。

## 5. 边界与失败处理

| 场景 | 行为 |
| --- | --- |
| 无播放队列 | 标题/歌手显示「暂无歌曲 / 请先导入音乐」，进度归零、封面回落占位、下载按钮隐藏（`:167-185`） |
| 曲目时长为 0 | `seek_to_progress_ratio()` 直接 seek 到 0（`assets/scripts/ui/music_app/controllers/music_app_player_controller.gd:31-34`） |
| 拖动到最右 | 全局 seek 夹到 `duration - 1`，不会误触发播放结束（`assets/scripts/ui/music_app/controllers/global/music_app_audio_controller.gd:283`） |
| 远程封面超时/非 200/空响应 | 返回 null，保持占位图，不重试（`assets/scripts/ui/music_app/views/player/music_app_player_view.gd:619-627`） |
| 快速连续切歌 | `request_id` 校验丢弃旧封面回调（`:584-587`） |
| 歌词为空 | 歌词页显示「暂无歌词」，点空白处回封面（`:695-700`、`:397-410`） |
| 非插件曲目点下载 | 按钮不可见，不会走到下载逻辑 |
| 下载控制器缺失 | `_get_download_controller()` 返回 null，下载按钮隐藏（`:279-282`、`:336-338`） |
| 页面关闭 | `_exit_tree()` 退订三个播放事件并断开下载信号（`:232-236`、`:270-277`），避免悬挂回调 |

## 8. 已知限制与后续

- **无分享 / 评论入口**：与任务描述不符，当前代码没有这两个能力的 UI 或接口；若后续接入，需要新增按钮、弹窗 ID 与插件侧接口。
- **无后台音频连接状态**：页面只显示音源名（`track.source`），Android 后台音频服务的运行/连接状态没有曝光；排查「后台不播」仍需看 logcat。
- **封面缓存无上限**：`_artwork_texture_cache` 只增不删，长时间浏览大量插件曲目会累积纹理内存，后续可加 LRU。
- **下载按钮不覆盖本地曲目**：本地曲目 `plugin_id` 为空，按钮直接隐藏，无法从播放器页删除本地文件。
- **歌词来源单一**：只读 `lyric_path`（本地旁挂文件），插件 `get_lyric()` 返回的歌词尚未接入播放器页（详见歌词文档）。
- **进度条只能点击/拖动 seek**：没有「拖动时预览波形/缩略图」，也没有快进 10 秒的长按手势。
