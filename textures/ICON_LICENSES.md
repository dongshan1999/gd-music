# Icon assets

The SVG icons in this directory were replaced with icons from [Lucide](https://github.com/lucide-icons/lucide), downloaded from the official icon source:

- https://raw.githubusercontent.com/lucide-icons/lucide/main/icons/
- License: https://github.com/lucide-icons/lucide/blob/main/LICENSE

Lucide is distributed under the ISC License. Lucide also identifies the Feather-derived icons in its license file; those icons retain the MIT License notice. The project uses the icon files with their stroke color set to `#FFFFFF` and their stroke width adjusted to `1.8`. The SVG files keep a `24x24` layout size, while their Godot `.svg.import` settings use the native `svg/scale=1.0` so the imported textures keep their original 24px layout size. Larger controls should size their icon nodes explicitly rather than changing the global SVG import scale.
